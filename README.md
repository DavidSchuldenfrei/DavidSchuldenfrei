# Hi, I'm David Schuldenfrei 👋

Staff Engineer at **[Cross River](https://www.crossriver.com/)**, based in Israel.
I like building developer tools that remove friction from everyday work: test runners,
code generators, and debugging aids.

## 🔧 Projects

- **[gtest-adapter](https://github.com/DavidSchuldenfrei/gtest-adapter)**: A VS Code extension
  that shows all your GoogleTests in a tree view so you can run and debug them, jump to source,
  and use CodeLens actions. It also supports parameterized tests and can re-run tests automatically after builds.
- **[DumpVisualizer](https://github.com/DavidSchuldenfrei/DumpVisualizer)**: A Visual Studio
  debugger visualizer for any object, inspired by LINQPad's `Dump()`.
- **[TypescriptGenerator](https://github.com/DavidSchuldenfrei/TypescriptGenerator)**: Generates
  TypeScript models from .NET assemblies, plus Angular service wrappers for ASP.NET Web API controllers.

## 🛠️ Tech I work with

C# · .NET · TypeScript · C++ · VS Code & Visual Studio extensibility
